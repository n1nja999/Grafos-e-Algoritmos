# Teoria dos Grafos em Python

Este repositório reúne implementações fundamentais de estruturas de dados e algoritmos da **Teoria dos Grafos**, cobrindo representações em memória (Matriz e Lista de Adjacência), validações de consistência estrutural, algoritmos de travessia (DFS e BFS) e cálculo de caminhos mínimos com pesos (Dijkstra).

---

## 📁 Estrutura de Arquivos Sugerida

```
├── README.md
├── menu_grafos.py              # Grafo orientado com menu interactivo
├── grafo_nao-orientado.py      # Representações (Matriz e Lista) sem direção
├── grafo_orientado.py          # Grafo direcionado com Menu, DFS e BFS
├── dijkstra_nao_orientado.py   # Menor caminho em grafo não direcionado com pesos
└── dijkstra_orientado.py       # Menor caminho com fila de prioridade e validações
```

### Pré-requisitos
- **Python 3.8+** instalado.
